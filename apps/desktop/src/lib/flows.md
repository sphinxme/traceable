# 关键流程骨架

> 本文只讲角色与时序骨架；分支、边界与失败语义见对应 JSDoc 与分层 README。

## perform 流水线

所有结构交互最终都收敛到 `Panel.perform`：

```
非动画：op() → await settle() → 焦点
动画：  源命名 → startViewTransition(op → await settle() → 目标命名)
        → 动画结束 → 清理 → 焦点
```

`perform` 是流程唯一所有者：op 至多执行一次、结果必达、并发不排队；失败时不改数据/折叠、不做目标命名、不发焦点。

## 周历 → 大纲定位

```
点击事件段 → 门面收集各面板的搜索地址
→ 同任务循环选中下一个 → 配对回投给产出它的面板
→ 编辑器必要时先跨 home 导航 → 展开祖先链
→ await settle() → 按地址找回条目实例 → 滚动 + 高亮
```

## 大纲 → 周历

```
事件指示条 hover → 门面路由高亮开/关 → 周历事件段响应
事件指示条 click → 门面路由定位 → 周历选择“离现在最近”的段 → 滚动 + 短时高亮
```

## 跨面板拖拽

```
dragstart 定格源侧载荷 → dragover 纯读预检
→ drop 定稿目标侧 → 目标面板 perform
→ dragend 终结会话
```

同面板默认 move、metaKey 切 link；跨面板默认 link、metaKey 切 move。被拒路径不产生 perform，光标即反馈。

## Enter 新建

按光标位置与折叠态分四类：空行上浮、子列表插入、父列表前/后位插入、正文截断。所有分支最终都只产生一次 `perform`。

## zoom 导航

编辑器导航栈的延伸/截断会推导“条目 ↔ 页根”的配对；跳变关系走无动画硬切。
